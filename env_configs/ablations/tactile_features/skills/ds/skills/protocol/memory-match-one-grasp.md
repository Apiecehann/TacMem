## How

Use one progressive grasp per can and repeat the same commands for reference and candidates. Save marker_anisotropy at both grip commands and compare its change across cans. Read the public can pose before and after the lift and sag actions for follow-through. The original hardness and grip-validity checks are unavailable; do not reconstruct them from an assumed value. A missing property is omitted from matching, not treated as a mismatch. Return each probed can before opening, then transport the selected candidate.
