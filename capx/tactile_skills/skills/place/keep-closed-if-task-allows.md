## How

Check what the task actually scores before adding a release to the end of it.
When the answer is a reading rather than a final placement, the episode can end
with the object still held.

## Traps

- A release is not free even when it succeeds: it costs a re-approach, and the
  re-approach is where grasp accuracy is lost ([[one-call-approach]]).
- Once released, the object is somewhere new, so every reading taken afterwards
  describes a different grasp than the one the judgement was made from
  ([[preserve-existing-grasp]]).
- This is a licence to skip the release, not to skip the check. If the task
  does score the object's final resting state, the release is part of the task
  and wants the full placement recipe ([[unload-before-open]],
  [[settle-after-release]]).
